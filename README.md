# ULTRON Oráculo — documentação do cliente pessoal

Documentação pública do cliente pessoal rclone para operações autorizadas no Google Drive. Este repositório contém somente a página inicial e a política de privacidade; não hospeda o cliente, arquivos do Drive ou credenciais.

- [Página inicial](index.html)
- [Política de privacidade](privacidade.html)

HTML estático com CSS embutido, sem JavaScript, cookies, análise de uso ou dependências externas. Publicação por GitHub Pages a partir da raiz da branch `main`.

Mantenedor e contato: [MarconiTeles](https://github.com/MarconiTeles). O cliente pessoal não é apresentado como verificado pelo Google.
